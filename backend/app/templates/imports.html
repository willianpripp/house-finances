Import Statement

Upload a credit-card CSV/MD or a bank-checking PDF statement. Select the account first and the filename pattern its parser expects shows up under the dropdown. Or paste checking / credit-card activity raw before the official statement closes, useful mid-month to keep /debts fresh.

or drop a file here

One row per line: DATE   DESCRIPTION   AMOUNT. Tabs or 2+ spaces between fields. Negative = debit (paren OK: (534.89)). No SavingsSnapshot is written from paste — only the PDF statement closes the period.

Vertical recent-activity layout, one stanza per transaction. Stanzas are Type / Purchase|Payment|Refund / DateMon DD YYYY / merchant / [product] / Status / Completed / Amount / $X.XX. Pending and Scheduled rows are skipped automatically.
